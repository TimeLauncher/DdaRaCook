# 온디바이스 호출어 구현

상태: `CODE_COMPLETE_DEVICE_PENDING`

## 동작

- 조리 화면에서 폰 마이크로 `따라쿡` 호출어를 계속 감지한다.
- 호출되면 짧게 `네.`라고 답하고, 그 응답이 시작되는 즉시 기존 Android STT로 한 문장 명령을 받는다.
- `확인해줘`, `다음`, `이전`, `다시`, `아직`, `재료` 명령은 기존 상태 머신으로 전달한다.
- 앱이 백그라운드로 이동하거나 조리 화면을 벗어나면 호출어 감지를 중지한다.
- 단계 안내 등 앱 TTS가 재생되는 동안에도 호출어 감지를 유지한다. 이때 `따라쿡`이 감지되면 기존 안내를 중단하고 `네.` 응답으로 교체한다.
- `네.` TTS와 명령 STT는 의도적으로 겹쳐 사용자가 응답 종료를 기다리지 않아도 된다.
- Android 명령 STT가 마이크를 독점하는 동안에만 호출어 감지를 일시 정지하고, 명령 인식이 끝나면 다시 시작한다.
- 글래스 마이크나 Meta AI 호출어를 가로채지 않으며 폰 마이크만 사용한다.

## 모델과 의존성

- Vosk Android `0.3.75`, Apache License 2.0
- JNA Android `5.18.1`, Apache License 2.0 선택 사용
- 한국어 모델 `vosk-model-small-ko-0.22`, Apache License 2.0
- 공식 모델 URL: `https://alphacephei.com/vosk/models/vosk-model-small-ko-0.22.zip`
- 다운로드 크기: `86,914,329` bytes
- SHA-256: `eea36124087fed26c59996a4761519458e3bd185e8ea9d9865ad8760c4a1d989`

모델은 최초 조리 화면 진입 때 한 번 다운로드하고 SHA-256을 검증한 뒤 앱 내부
`files/voice-models/`에 설치한다. 이후 호출어 감지는 네트워크 없이 동작한다. 모델 디렉터리는
클라우드 백업과 기기 이전 대상에서 제외한다.

## 실기기 확인

1. 조리 화면에서 `음성 호출: '따라쿡'이라고 부르세요`가 표시될 때까지 기다린다.
2. 폰에서 1m 이내 거리로 `따라쿡`이라고 말한다.
3. `네.`가 들리기 시작하면 기다리지 말고 바로 `확인해줘`라고 말한다.
4. 최근 음성 인식 문구와 카메라 확인 동작이 이어지는지 확인한다.
5. 단계 안내 음성이 재생되는 동안 `따라쿡`이라고 불러 안내가 중단되고 `네.`로 응답하는지 확인한다.
6. 앱을 백그라운드로 보내 호출어 감지가 종료되는지 확인한다.

실기기 호출 성공과 주방 소음 환경의 오인식률을 확인하기 전에는 `DONE`으로 표시하지 않는다.
