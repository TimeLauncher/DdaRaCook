# 서버 전송 이미지 정규화

상태: `CODE_COMPLETE_DEVICE_PENDING`

서버 판정 요청의 `currentImage`와 `startImage`에만 다음 파이프라인을 적용한다.

- PNG와 JPEG 입력을 모두 디코딩한다.
- EXIF 회전을 픽셀에 반영한다.
- 회전 반영 후 가로폭이 1024px를 넘으면 중앙을 기준으로 정확히 1024px만 남긴다.
- 가로폭이 1024px 이하이면 확대하거나 자르지 않는다.
- 세로축은 자르거나 리사이즈하지 않는다.
- 결과를 JPEG 품질 80으로 인코딩한 뒤 Base64로 서버에 전송한다.
- 촬영 원본 URI와 단계별 사진 갤러리 파일은 변경하지 않는다.

파이프라인 버전은 `center-x1024-jpeg80-exif-baked-v2`다.

## 검증

- 3024×4032 입력 → 왼쪽 1000px부터 1024×4032 크롭
- 960×1280 입력 → 960×1280 유지
- 1025×700 입력 → 1024×700 크롭

실기기에서 실제 판정 서버로 보낸 이미지의 디코딩 크기를 확인하기 전에는 `DONE`으로 표시하지 않는다.
