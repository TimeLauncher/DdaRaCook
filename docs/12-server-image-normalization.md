# 서버 전송 이미지 정규화

상태: `CODE_COMPLETE_DEVICE_PENDING`

서버 판정 요청의 `currentImage`와 `startImage`에만 다음 파이프라인을 적용한다.

- PNG와 JPEG 입력을 모두 디코딩한다.
- EXIF 회전을 픽셀에 반영한다.
- 회전 반영 후 상단 40%를 제거하고 하단 60%를 유지한다.
- 남은 이미지의 긴 변이 1024px를 넘으면 비율을 유지해 긴 변 1024px로 축소한다.
- 긴 변이 1024px 이하이면 확대하지 않는다.
- 결과를 JPEG 품질 80으로 인코딩한 뒤 Base64로 서버에 전송한다.
- 촬영 원본 URI와 단계별 사진 갤러리 파일은 변경하지 않는다.

파이프라인 버전은 `bottom60-long1024-jpeg80-exif-baked-v3`다.

## 검증

- 3024×4032 입력 → 하단 3024×2419 유지 → 1024×819 축소
- 960×1280 입력 → 하단 960×768 유지, 확대하지 않음
- Android 실기기에서 상단 40% 색상은 제거되고 하단 색상만 JPEG 결과에 남는지 확인

실기기에서 실제 판정 서버로 보낸 이미지의 디코딩 크기를 확인하기 전에는 `DONE`으로 표시하지 않는다.
