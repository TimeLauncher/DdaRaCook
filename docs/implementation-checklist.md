# 따라쿡 앱 구현 체크리스트

기준 문서: `따라쿡_앱화면_기능명세서_v1.md` v1.0  
점검 기준일: 2026-08-13
점검 대상: 현재 Android 프로젝트 소스 코드

검증 결과: `testDebugUnitTest` 통과(16개, 실패 0) · 실제 휴대폰 `connectedDebugAndroidTest` 통과(6개, 실패 0) · 서버 `pytest` 통과(6개, 실패 0) · `assembleDebug` 성공
항목 집계: 2026-08-13 비-DAT 앱·서버·평가 항목 구현 후 재점검. Meta DAT SDK·실기기 항목은 제외

> 집계는 세부 항목 수 기준이며 제품 완성도를 뜻하지 않는다. Fake 구현은 아래에서 명시적으로 구분했으며 실제 DAT·서버 연동 완료로 계산하지 않았다.

## 표시 기준

- `[x]`: 현재 코드에 동작 경로가 구현되어 있음
- `[ ]`: 미구현이거나, 모델/화면 일부만 있고 명세의 완료 조건을 충족하지 못함
- `부분`: 구현된 범위와 남은 범위를 항목 안에 함께 표시
- `Fake`: 시연용 가짜 구현으로만 동작하며 실제 기기·서버 연동 완료로 보지 않음

## 12. 현재 구현 요약

현재 구현은 **Compose 앱 + 영속 상태 머신 + Android STT/TTS + Fake/실제 판정 서버 선택 흐름** 단계다. 비-DAT 범위의 레시피 편집·복구·상태 전이·서버 오류 처리·캡처 기록·ground truth 평가·접근성 UI가 구현됐다. 남은 미완료 항목은 Meta DAT SDK, 실제 글래스 등록·권한·세션·촬영, DAT 원본 정규화 실측 및 실기기 평가다.
