## 붙여넣을 본문

```
[3번] 이미지 요청 — 지난번보다 요청이 줄었습니다 🙏
(앞서 보낸 캡처 빌드 요청은 이걸로 대체해 주세요)

■ 결론부터
① 안경으로 아무거나 3~5장 찍고, 긴 변 1280px로 축소한 것 + 축소 전 원본을
   같이 주세요.  ← 이것만 W1 중에 급합니다
② 실서비스용 축소는 W2까지 넣어주시면 됩니다.
   → 캡처 빌드 전달은 철회합니다. 안경 등록 절차도 해결됐습니다.

■ 왜 줄었나
안경 원본을 Gmail로 직접 받아 EXIF까지 검사했습니다.
 - 회전: Orientation = 1 — 안경이 이미 픽셀에 반영해서 저장합니다. 처리 불필요
 - 촬영: 원본을 제가 직접 받을 수 있어서 빌드 없이 촬영 가능
남은 불확실 구간이 "축소" 한 단계뿐이라, 그것만 3~5쌍 대조하면 끝납니다.

■ 축소 규격
 - JPEG quality 80
 - 긴 변 1280px, 비율 유지, 확대 금지
 - 긴 변 값은 상수 하나로 빼두세요
   (T2-4에서 1024나 768로 낮출 가능성이 높고, 그때 한 줄로 끝납니다)

■ ★ 색공간은 건드리지 마세요
안경이 Display P3로 저장합니다(실측). sRGB 변환 여부는 서버에서 켜고 끄며
A/B로 정할 거라, 앱에서 미리 바꾸면 그 실험이 불가능해집니다.
ICC 프로파일을 그대로 통과시켜 주세요. EXIF도 굳이 안 지우셔도 됩니다.
→ 지난번에 "sRGB로 맞춰달라"고 했던 건 취소입니다. 할 일이 하나 줄어듭니다.

■ ★ 딱 하나만 확인 부탁드립니다
축소한 파일의 EXIF Orientation이 여전히 1인지만 봐주세요.
원본은 깨끗한데 재인코딩하면서 회전 태그가 새로 붙는 경우가 있습니다.
붙으면 앱 화면은 멀쩡한데 서버 AI만 누운 사진을 보게 되고,
"팬이 안 보인다"만 반복해서 원인 찾는 데 반나절 갑니다.

■ ①은 정식 빌드가 아니어도 됩니다
같은 안드로이드 코드 경로로 축소한 결과이기만 하면 됩니다.
비교하려는 게 "안드로이드 축소 vs 파이썬 축소"라서, 임시 코드로도 충분합니다.

■ 파일 전달 — Gmail 파일첨부 / USB / 드라이브
디스코드·카톡은 EXIF를 지우고 재압축합니다(실측). 그러면 대조가 무의미해집니다.
Gmail은 지난주 검증했고 EXIF·ICC 모두 무손상이었습니다.
단, 공유 시트에서 "사진"이 아니라 "파일"로 첨부해 주세요.

■ 회신 부탁드립니다
 - 검증 샘플(축소본 + 원본) 3~5쌍 전달 가능 시점: ______
 - 축소 후 Orientation = 1 확인: ☐
 - 색공간·ICC 손대지 않음: ☐
 - 긴 변 목표값 상수화: ☐
 - 실서비스 축소 완료 예정: ______

①이 늦으면 제가 만든 축소본이 유효한지 몰라서 T2-3 정확도 숫자를 확정할 수
없습니다. W1 중에 부탁드립니다. ②는 W2까지 여유 있습니다.

상세 문서: (이미지규격_요청서.md Part 1 링크)
```

## 이 문안에 넣은 장치 (수정할 때 지우지 말 것)

| 장치 | 이유 |
|---|---|
| **첫 줄에 "요청이 줄었습니다"** | 두 번째 요청은 "또 늘었나" 하고 방어적으로 읽힙니다. 줄었다는 걸 먼저 말해야 나머지가 읽힙니다 |
| **"3~5장"과 "30쌍 아님"을 못박음** | 대충 읽으면 "촬영해달라는 거구나" 하고 부담을 느껴 미룹니다 |
| **취소된 항목을 명시적으로 언급** | "sRGB 취소"를 안 적으면 이전 판대로 구현해 버립니다. **줄어든 요청은 조용히 빼면 전달되지 않습니다** |
| **Orientation을 별도 ★ 섹션으로 분리** | 규격 표 안의 한 줄은 반드시 흘려 읽힙니다. 다른 규격은 놓쳐도 복구되지만 이건 반나절을 날립니다 |
| **"정식 빌드 아니어도 됨"** | ①이 ②를 기다리게 되는 오해를 차단합니다. 이게 없으면 "빌드 다 되면 드릴게요"로 W1이 통째로 날아갑니다 |
| **원본도 같이 요청** | 원본이 없으면 "다른 사진이라 다른 건지" 구분이 안 돼 대조가 성립하지 않습니다 |
| **마지막 줄에 일정 영향 명시** | "W1 중"만 쓰면 소프트한 요청으로 읽힙니다. "늦으면 T2-3 숫자를 못 쓴다"까지 있어야 우선순위가 전달됩니다 |
| **①/② 우선순위 분리** | 둘을 같은 무게로 쓰면 둘 다 W2로 밀립니다 |

## 회신 받은 뒤 할 일

1. 샘플 수령 (Gmail 파일첨부 · USB · 드라이브)
2. `python inspect_image.py 1번축소본.jpg` — 긴 변 1280 / 회전 1 / JPEG / RGB 확인
3. **같은 원본**을 내 스크립트로 축소해서 대조 (`이미지규격_요청서.md` Part 3)
4. 일치하면 T2-1 본 촬영 계속 (Part 2 계획대로)

> ⚠️ Orientation이 1이 아니면 **촬영 시작 전에** 1번에게 알리세요.
> 20쌍을 다 찍은 뒤 발견하면 전부 다시 만들어야 합니다.
> (다행히 `raw/` 원본을 보관하므로 재촬영이 아니라 재생성으로 끝납니다)
